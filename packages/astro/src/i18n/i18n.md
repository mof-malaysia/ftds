## When to use

- Every Astro component with built-in text (Skiplink, Masthead, Breadcrumb, Callout's close button and so on) installs `astro-i18n` and takes its words from it. You rarely import it yourself.
- Import it to write your own components in the same two languages, to change a wording for the whole site, or to format dates the way the blocks do.
- Text that is your content (titles, descriptions, button labels) is yours to pass in, in the page's language.

## Usage

```astro
---
import { formatDate, isoDate, label, resolveLang, type Lang } from "@/lib/ftds/i18n";

interface Props {
  published: string;
  lang?: Lang;
}

const { published, lang: langProp } = Astro.props;
const lang = resolveLang(langProp, Astro.currentLocale);
---

<p>
  {label(lang, "published")}:
  <time datetime={isoDate(published)}>{formatDate(lang, published)}</time>
</p>
```

## Notes

- Components pick their language from their `lang` prop, then the page's `Astro.currentLocale`, then BM: that order is `resolveLang`. `"en-MY"` counts as `"en"`.
- `Lang` is `"ms" | "en"`. `label(lang, key)` returns one label; `labels` holds both dictionaries, and `LabelKey` is the type of their keys.
- Some labels have placeholders: fill them with `format`, e.g. `format(label(lang, "page"), { n: 2 })` gives "Halaman 2".
- `formatDate` writes a date in the language in Malaysia time ("31 Oktober 2026"); `isoDate` gives the `datetime` value ("2026-10-31").
- The dictionary is your code after install (`lib/ftds/i18n/index.ts`). Change a wording there once for the whole site; add a language by adding a dictionary with the same keys.
