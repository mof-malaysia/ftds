## When to use

- Use `SiteFooter` at the bottom of an agency or landing site that has many pages to link to.
- Use `Footer` on its own for a citizen service or a small site. Every public page needs it, so place it directly under `SiteFooter` too.

## Usage

Wrap both in one `<footer>` and pass `as="div"` to each, so the page has a single contentinfo landmark. The default slot (address, social links) goes under the logo:

```astro
---
import SiteFooter from "@/components/ui/site-footer.astro";
import Footer from "@/components/ui/footer.astro";
import Link from "@/components/ui/link.astro";
import Facebook from "@/components/ui/icons/facebook.astro";
import Youtube from "@/components/ui/icons/youtube.astro";

const socials = [
  { label: "Facebook", href: "https://www.facebook.com/MOFMalaysia", Icon: Facebook },
  { label: "YouTube", href: "https://www.youtube.com/@MOFMalaysia", Icon: Youtube },
];
---

<footer>
  <SiteFooter
    as="div"
    logoTitle="Kementerian Kewangan Malaysia"
    groups={[
      {
        title: "Mengenai kami",
        links: [
          { label: "Profil kementerian", href: "/profil" },
          { label: "Carta organisasi", href: "/organisasi" },
        ],
      },
      {
        title: "Perkhidmatan",
        links: [
          { label: "Bayar bil", href: "/bayar" },
          { label: "Pendaftaran pembekal", href: "/pembekal" },
        ],
      },
    ]}
  >
    <img slot="logo" src="/jata-negara.png" width="46" height="36" alt="" class="h-9 w-auto" />
    <p>Kompleks Kementerian Kewangan, No. 5 Persiaran Perdana, Presint 2, 62592 Putrajaya</p>
    <div class="flex gap-1">
      {
        socials.map(({ label, href, Icon }) => (
          <Link
            href={href}
            newTab
            underline="none"
            aria-label={label}
            class="text-txt-black-700 hover:text-txt-black-900 flex size-11 items-center justify-center rounded-md"
          >
            <Icon aria-hidden="true" />
          </Link>
        ))
      }
    </div>
  </SiteFooter>
  <Footer
    as="div"
    tone="well"
    owner="Kementerian Kewangan Malaysia"
    links={[
      { label: "Dasar privasi", href: "/privasi" },
      { label: "Penafian", href: "/penafian" },
    ]}
  />
</footer>
```

## Notes

- React's `SiteFooterSection`, `SiteFooterInfo`, `SiteFooterLogo`, `SiteFooterLinkGroup` and `SiteFooterLink` parts are props and slots here: `logoTitle` and the `logo` slot, the default slot for the info column, and `groups` for the link columns. React's `render={<div />}` is `as="div"`.
- Each group's `title` renders an `h2` that names its `<nav>`. `titleId` sets the prefix of those ids (generated by default). The `groups` slot adds custom columns after them.
- A group shows every link; `linkCount` shows only the first few. For long lists, link to an index page instead.
- Four groups fill the desktop row beside the info column; on mobile they sit two per row.
- Give `Footer` `tone="well"` under a `SiteFooter`, so the two read as one band.
- The logo image is decorative when `logoTitle` names the agency: give it `alt=""`. `logoTitle` renders as a paragraph, not a heading; the `logoTitle` slot replaces it.
- Icon-only social links need an `aria-label` naming the network.
- It is a Well band with no dividers, hidden when printing; don't add borders or cards inside it.
- The `site-layout` template shows it with the rest of the site chrome.
